Reused EventsRoutes, AtlasShell, RequireAtlasIdentity, existing CSS tokens/layout and repository Vitest/typecheck/build pipeline. Added /events/cards and a working link from /events. No new service, dependency, schema, provider or execution architecture.

Carta Mayor is a deliberately small local practice ruleset, not an implementation of Hokm, Shelem or Pasur. 52 unique cards, five-card hands, ace high, rank comparison, ties score zero, one replacement each until the deck is empty, 26 rounds. Bot always selects its lowest card based on its own hand. Scores, revealed round and restart are functional. Spanish rules, accessible card names including suit, live round announcements, keyboard buttons, visible focus and wrapping mobile layout.

All game state is component memory. No storage, network, tokens, user records, payments or wagers are added. The UI projection omits opponent hand and draw order, but this is NOT a security boundary: browser state can be inspected. Multiplayer must use a separately verified authoritative server with authenticated membership, private per-player projections, turn/version validation, replay protection and revocation tests. Do not reuse this local state as a trusted network payload.
